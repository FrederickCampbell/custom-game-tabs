# Custom Game Tabs

Make RuneLite's game tabs your own!

## Features
- Move and resize game tabs.
- Freely arrange tabs or snap them together.
- Customize button size, spacing, colors and opacity.
- Hide tabs or tuck them into a collapsible drawer.
- Save and switch between activity layouts.

Supports the Resizable Modern game interface.
